# KWR - Gestão de RH Premium 🏢

Um site moderno, elegante e interativo para a KWR Gestão de RH, apresentando uma experiência premium com animações suaves, parallax effects e design sofisticado.

## 🚀 Stack Tecnológico

- **React 18** - Library UI
- **Vite** - Build tool super rápido
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript ES6+** - Modern JavaScript

## 📋 Características

✨ **Design Premium**
- Paleta de cores sofisticada (tons quentes e escuros)
- Tipografia elegante com fontes serif
- Glassmorphism effects

🎬 **Animações & Interatividade**
- Scroll reveal animations
- Parallax sections
- Scroll progress bar
- Smooth scrolling
- Hover effects dinâmicos

📱 **Responsivo**
- Mobile-first approach
- Breakpoints em md (768px) e lg (1024px)
- Otimizado para todos os dispositivos

📊 **Seções**
- Hero com background video
- About com cards interativos
- Showcase com scroll horizontal
- Services grid
- Parallax section
- CTA section
- Footer com navegação

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Mayasfagundes/Rh-p-gina.git
cd Rh-p-gina

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:3000`

## 🔨 Scripts Disponíveis

```bash
# Desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## 🚢 Deploy no Vercel

1. Conecte seu GitHub ao Vercel
2. Selecione este repositório
3. Vercel detectará automaticamente:
   - Framework: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy automático! 🎉
